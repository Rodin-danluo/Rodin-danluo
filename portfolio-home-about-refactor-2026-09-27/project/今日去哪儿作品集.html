今日去哪儿｜城市微文旅的即时出行系统

今天不宅了，去哪？

基于天气、位置、时间与心情，为年轻人生成一个今天就能执行的附近出门方案。这个 case 重点呈现我如何从产品策略、UX 推导到 UI 规范，把“想出门”压缩成“现在就走”。

负责人核心贡献

主导从 0 到 1 的产品策略定位、全链路 UX 推导与高保真 UI 表达，并用 AI 工具链完成概念验证与作品集叙事整合。

DEFINITION / MVP05 / 08
PRODUCT DEFINITION / MVP STRATEGYSECTION 05 / 08

产品定义与 MVP 策略

把连续决策压缩成一个“今日出门答案”

MVP 不追求覆盖所有生活服务，而是优先验证用户是否愿意接受“系统替我做第一次选择”。因此首页推荐、出门卡和召唤链路被放在最高优先级。

High impact / Low effort

今日推荐

首屏给答案，减少地点信息流带来的继续筛选。

High impact / Medium effort

出门卡片

把路线、预算、天气、准备清单合并成行动确认页。

Medium impact / Medium effort

今日召唤

基于已确认的出门状态，降低邀约的心理门槛。

Later iteration

成长记录

把出门偏好沉淀为下一次推荐的个人化反馈。

CORE EXPERIENCE / LAZY MODE06 / 08
INFORMATION HIERARCHY / CORE SCREENSSECTION 06 / 08

核心功能深度推演

三个功能页共同服务一件事：少想一点，快走一步

核心亮点 01

首页不是信息流，而是当日答案

信息层级优先展示目的地结论、距离、体验标签和主行动按钮，弱化长列表。

  • 顶部放置当前情境，让推荐理由可解释。
  • 主卡片只承载一个最优解，减少备选干扰。
PM 策略：首屏去除瀑布流，直接给“今日唯一解”。

核心亮点 02

出门卡把准备成本前置消化

路线页把时间、交通、预算和携带物转译为用户出发前能确认的信息。

  • 先给总体耗时和花费，再给路线细节。
  • 准备清单作为辅助确认，降低临出门焦虑。
UX 取舍：先给确定性，再展开路线细节。

核心亮点 03

先展示行动状态，再发起轻邀约

把“你要不要出来”改写为“我已准备出发，你可以加入”，降低决策成本。

  • 出门卡是信息完整且低打扰的分享载体。
  • 同行小队同步集合点、成员状态和消息通知。
社交设计：用行动状态替代正式邀约压力。

设计系统与设计规范

视觉去噪：让晴空蓝服务信息，而不是抢走注意力

保留“轻松、当下、附近生活”的品牌感，但降低背景装饰和玻璃拟态重量。组件字阶围绕决策效率设置：结论最大，理由次之，辅助信息保持克制。
